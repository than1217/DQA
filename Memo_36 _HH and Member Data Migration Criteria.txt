	4
	Removal of leading, trailing, and multiple spaces between names (first_name, middle_name, last_name, school_name, health_center_name, etc.)
example:
Peter  John to Peter John,
Maria     Isabel to Maria Isabel,
Aba   Nakaka    Basa to Aba Nakaka Basa


Applicable to all DB tables
	/*
TRIM - removes leading and trailing spaces.
REGEXP_REPLACE(table.field, '\\s+', ' ') - removes consecutive spaces in between string values and maintains 1 space (‘ ‘)
*/
TRIM(REGEXP_REPLACE(table.field, '\\s+', ' '))
	5
	Removal of consecutive periods/dots (first_name, middle_name, last_name, school_name, health_center_name, etc.)
example:
Ma.. to Ma. 


Applicable to all DB tables
	/*
REGEXP_REPLACE(table.field, '\\.+', '.')
*/
REGEXP_REPLACE('Ma.. Ann', '\\.+', '.')
	6
	Removal of consecutive dashes (first_name, middle_name, last_name, school_name, health_center_name, etc.)
example:
— to -,
Mary—Ann to Mary-Ann


Applicable to all DB tables
	/*
REGEXP_REPLACE(table.field, '\\-+', '-')
*/
REGEXP_REPLACE('Mary–Ann', '\\-+', '-')

	Identify and Tag string with invalid characters defined per string datatype columns for correction in operation (Beneficiary Update System)
Breakdown of this specific Whitelist:
* A-Za-z0-9: All alphanumeric English characters (letters and numbers).
* Ññ: Specifically allows uppercase and lowercase N-with-tilde.
* \s: Allows spaces.
* ': Allows apostrophes.
* \-: Allows dashes/hyphens.
* \.: Allows periods.
	/* 
Identification using whitelists of valid characters in a string datatype column
*/
SELECT a.person_id, a.first_name
FROM cbms_4ps_roster_4562438 a
WHERE a.first_name REGEXP '[^A-Za-z0-9Ññ\\s\'\\-\\.]'
limit 1;
